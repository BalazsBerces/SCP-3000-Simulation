# Seed defines the map only; history is not deterministic

The seed generates only the Store (layout, Departments, Landmarks; the Pillars and their Sectors are a fixed grid chosen by the world's Pillar layout, one of the five in the README, never by the seed); starting Villages and everything that happens afterwards vary per run. We rejected full determinism (fixed tick, seeded RNG everywhere) because the observer wants each run to unfold differently even on a favourite map. As a consequence, an interesting world can only be kept by saving its full state (Pillar layout, Furniture, Villagers, Beliefs, chronicle), so save/load is designed in from the start, and bugs cannot be reproduced from a seed alone.
